# APEX Career Command Center

The Career Command Center is the connected overview for a user's saved career activity. It is available at `/features/career-command-center` and linked from the dashboard.

## Data sources

The page combines authenticated, user-scoped APIs:

- `GET /api/intelligence/career-pipeline` — application status counts, preparation-task progress, and upcoming/overdue pending timeline events.
- `GET /api/intelligence/overview` — saved practice totals and recent activity.
- `GET /api/intelligence/recommendations` — deterministic recommendations based on saved assessments and practice activity.
- `GET /api/intelligence/roadmap` — active-goal preparation tasks and progress.
- `GET /api/intelligence/role-coverage` — coverage of role-template skills with recorded self-assessments.

The page fetches these endpoints on load and supports manual refresh. It displays a concise action queue, a focus goal, application pipeline stages, skill-assessment coverage, recent practice activity and a weekly review.

## Action queue methodology

The queue is deterministic and assembled in the browser:

1. Pending overdue timeline events.
2. Pending upcoming timeline events.
3. The first incomplete task in the returned preparation roadmap.
4. Up to two deterministic practice recommendations.

The list is capped at five entries. It is not generated by an AI model, does not schedule work, and does not change any application or task status. Each item links to the relevant APEX workspace.

## Weekly review

The weekly review counts sessions started within the last seven days from the recent activity returned by the overview endpoint, timeline events marked completed, and preparation tasks marked completed. It is an on-demand view of recorded activity, not a scheduled report or notification. The session count is bounded by the overview endpoint's recent-activity result set.

## Interpretation and limitations

- Application stages and timeline events are user-entered records.
- Preparation completion is user-reported checklist status.
- Skill coverage means a self-assessment exists for a role-template skill; it is not proficiency, employability or readiness.
- Practice counts and completion status do not prove mastery.
- The action queue is rule-based, not an AI-generated daily plan.
- The weekly review is not automatically delivered.
- The command center depends on authentication, PostgreSQL, applied migrations and generated Prisma Client.
- No external job-board crawling, employer contact, email, calendar sync, notifications or hiring predictions are performed.

Career Copilot is available separately through Agent Workbench. Sharing the limited saved career snapshot is an explicit per-message opt-in and is off by default.

## Phase 29: explicit timeline action controls

The command-center action queue now offers a **Mark done** control for overdue and upcoming timeline events. It is only rendered for timeline-backed items. The control sends a user-initiated `PATCH /api/job-events/:id` request with status `completed`, using the existing authenticated owner-scoped endpoint. On success the page refreshes its data and shows a status message; on failure it reports the API error. The application does not mark events complete automatically.

This is a limited, reversible-in-the-existing-timeline sense of recording user-reported completion; it does not send recruiter messages, alter an application stage, create calendar entries, or contact an employer. Other queue items remain navigation links. No background automation or external side effects are performed.

## Phase 29.2: approval-based action planner

The Command Center exposes unreviewed, non-timeline recommendations from its existing deterministic action queue. A user can dismiss a suggestion locally or explicitly accept it. To accept, the user selects one of their own saved jobs; the UI then sends a `POST /api/job-events` request to create a private timeline event attached to that job.

Accepted suggestions are scheduled for 24 hours after acceptance. The user can subsequently edit the date or details in Application Follow-ups. The UI explains this default before acceptance. Suggestions already backed by a timeline event are excluded from this planner to avoid creating duplicates. Dismissals are client-side only and are not persisted across reloads.

The planner does not use an AI model, does not infer an employer deadline, and does not contact recruiters or modify application statuses. The existing authenticated job-events API validates job ownership and request fields. No new database model or migration is introduced.

## Phase 32 integration

The tracker is rendered inside the Career Command Center. It replaces the earlier temporary, browser-only suggestion dismissal and job-timeline acceptance controls with durable per-user recommendation records. See [APEX Recommendation Tracking](apex-recommendation-tracking.md) for the model, API and migration contract.

## Phase 34 — Intelligent Gap Closure

The Career Command Center's Recommendation Tracker now merges deterministic, goal-specific skill gaps from `GET /api/intelligence/gap-closure` with practice and roadmap suggestions. Users explicitly accept, defer, dismiss or complete tracked actions. See [Intelligent Gap Closure](apex-intelligent-gap-closure.md).

## Phase 35 — Personalised Learning Engine

The Command Center now includes a per-goal learning sequence derived from incomplete roadmap tasks, latest goal-linked self-assessments, approved evidence links and recency of goal-linked module practice. See [Personalised Learning Engine](apex-personalised-learning-engine.md).

## Phase 36 — Intelligent Practice Orchestrator

The learning path can now launch a goal-linked practice session from a supported roadmap task. The server verifies ownership and maps only registered internal module destinations. OA Arena and Interview Lab automatically open the new session. See [Intelligent Practice Orchestrator](apex-intelligent-practice-orchestrator.md).
