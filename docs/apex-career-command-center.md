# APEX Career Command Center

The Career Command Center is the connected overview for a user's saved career activity. It is available at `/features/career-command-center` and linked from the dashboard.

## Data sources

The page combines authenticated, user-scoped APIs:

- `GET /api/intelligence/career-pipeline` — application status counts, preparation-task progress, and upcoming/overdue pending timeline events.
- `GET /api/intelligence/overview` — saved practice totals and recent activity.
- `GET /api/intelligence/recommendations` — deterministic recommendations based on saved assessments and practice activity.
- `GET /api/intelligence/roadmap` — active-goal preparation tasks and progress.
- `GET /api/intelligence/role-coverage` — coverage of role-template skills with recorded self-assessments.

The page fetches these endpoints on load and supports manual refresh. It displays a concise action queue, a focus goal, application pipeline stages, skill-assessment coverage, recent practice activity and a weekly review.

## Action queue methodology

The queue is deterministic and assembled in the browser:

1. Pending overdue timeline events.
2. Pending upcoming timeline events.
3. The first incomplete task in the returned preparation roadmap.
4. Up to two deterministic practice recommendations.

The list is capped at five entries. It is not generated by an AI model, does not schedule work, and does not change any application or task status. Each item links to the relevant APEX workspace.

## Weekly review

The weekly review counts sessions started within the last seven days from the recent activity returned by the overview endpoint, timeline events marked completed, and preparation tasks marked completed. It is an on-demand view of recorded activity, not a scheduled report or notification. The session count is bounded by the overview endpoint's recent-activity result set.

## Interpretation and limitations

- Application stages and timeline events are user-entered records.
- Preparation completion is user-reported checklist status.
- Skill coverage means a self-assessment exists for a role-template skill; it is not proficiency, employability or readiness.
- Practice counts and completion status do not prove mastery.
- The action queue is rule-based, not an AI-generated daily plan.
- The weekly review is not automatically delivered.
- The command center depends on authentication, PostgreSQL, applied migrations and generated Prisma Client.
- No external job-board crawling, employer contact, email, calendar sync, notifications or hiring predictions are performed.

Career Copilot is available separately through Agent Workbench. Sharing the limited saved career snapshot is an explicit per-message opt-in and is off by default.
